# FeroSSH v1.1.0

*Secure connections. Forged in Rust.*

FeroSSH 1.1 is about working faster in tmux and in many tabs: tmux's own keys can drive FeroSSH's tabs and panes, new shells can start in the directory you're already in, sessions can have names of their own, and there are 30 more colour themes. If you're new to FeroSSH, the [1.0 release notes](https://github.com/jkobierczynski/FeroSSH/releases/tag/v1.0.0) introduce it.

## New

- **tmux keybindings for tabs and panes.** Turn on Session > Use tmux keybindings for tabs and panes, and in a tmux session your tmux prefix (read from the server, Ctrl+B by default) followed by `c`, `%`, `"`, `n`, `p`, `0`-`9`, arrows, `x`, `d`, `[` and the other usual keys works FeroSSH's native tabs and panes. Arrow, resize and scroll keys repeat without the prefix, like tmux's `bind -r`. Pressing the prefix twice sends it to the server. Off by default.
- **Splits in the same directory.** Window > Split right in same directory and Split down in same directory start the new pane's shell where the focused pane's shell is, in tmux or plain SSH.
- **Find and resize in the file transfer view.** `/` searches the remote listing or the Local PC section by name (any case, or with `*` and `?`), and dragging the Local PC and Transfers title bars gives each section more or fewer rows.
- **A start directory per host.** A connection's new *Start dir* field (`StartDir` in `ferossh.conf`) opens every new shell, tmux window and pane on that host in that directory. Session > Start new tabs and panes in this directory sets it from the focused pane.
- **Name your sessions.** Window > Rename session, a double-click on a tab, the tab's right-click menu or F2 in the Session manager gives a session a name of its own, shown on the tab and in the window title instead of the title the host sets. In tmux the name also renames the tmux window and comes back when you attach again.
- **Save a pane's whole output.** Session > Save this pane's output to a log writes the pane's scrollback and screen to a new sealed log file. Save output of all panes to logs does it for every pane in every tab.
- **30 more colour themes**, 44 in all: dark ones such as Kanagawa, Rose Pine Moon, Night Owl, GitHub Dark and Tokyo Night Storm, light ones such as Catppuccin Latte, GitHub Light, Solarized Light and Everforest Light, and classics including PuTTY's own colours. Settings > Theme now shows them in dark, light and warning/classic columns, and every theme keeps text readable (a contrast of at least 4.5:1).
- **A Tools menu.** The Connection manager, Session manager, File transfer, Port forwards, Command snippets and the Command palette moved from Settings to a new Tools menu. Their shortcuts are unchanged.
- **A complete user guide.** The [user guide](https://github.com/jkobierczynski/FeroSSH/tree/main/docs/guide) now covers every feature, with a reference of every menu item and shortcut and a page on sealed logs.
- **winget.** Releases can now be submitted to winget automatically when they are published, so `winget install jkobierczynski.FeroSSH` keeps up with new versions once the package is in winget.

## Fixed

- **tmux in the Connection manager is now an on/off switch.** Typing "off" or "on" in the old tmux text field attached to a tmux session with that name. The field is now a switch, like Old crypto, with a separate *tmux name* row (`main` unless you type one) that appears while it is on. Connections saved by older builds with `Tmux off` or `Tmux on` are read correctly.
- In the Session manager, F2, typing and the filter now show at once, without waiting for the window to repaint for another reason.
- Choosing the Session manager from the menu, or any side pane from the command palette, while it was open took two clicks to hide it. It now takes one.
