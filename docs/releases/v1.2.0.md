# FeroSSH v1.2.0

*Secure connections. Forged in Rust.*

FeroSSH 1.2 gives headless Linux servers a desktop over SSH, adds a standby hotkey that hides and shows FeroSSH from anywhere, and turns command snippets into files you can share, sort into categories and import from other tools. New tabs and splits now start where you already are. If you're new to FeroSSH, the [1.0 release notes](https://github.com/jkobierczynski/FeroSSH/releases/tag/v1.0.0) introduce it.

## New

- **Virtual desktops on headless servers.** Session > Open virtual desktop starts a desktop on a server with no screen and no RDP server, using Xvfb and x11vnc (or TigerVNC's Xvnc, which also resizes with the tab). It runs on a fresh display with a one-time password, only on the server's loopback, and is tunnelled through the SSH connection like Open remote desktop. The built-in VNC tab or an installed VNC viewer opens it, and closing the tab stops everything and removes its files. The Connection manager has a new *Virtual desktop* connection type, and a *Virtual desk* field picks the program to run.
- **Desktop size per connection.** A *Desk size* field for SSH, RDP, VNC and virtual desktop connections either follows the tab (the default) or keeps a fixed size such as 1920x1080.
- **Standby window.** Window > Standby window gives FeroSSH a global hotkey (Win or Ctrl with the key below Esc, Ctrl+Alt+Space, Scroll Lock, Pause, or one you press) that hides the window when it's in front and brings it back otherwise. It can also show and hide another program's window instead. That window is always shown again when standby goes off or FeroSSH closes. Off by default.
- **Snippets as files.** Each command snippet is now a `.snippet` file in `%APPDATA%\FeroSSH\snippets`, and its folder is its category (such as `Network/Cisco`). You can copy them to another PC, keep them in git or share them. Snippets in `ferossh.conf` move there at the first start, and a copy of the old file is kept. The snippets pane groups them under category headings, and Tools > Open snippets folder opens the folder.
- **Import snippets.** File > Import snippets reads Windows Terminal `sendInput` actions and `.wt.json` snippets, SecureCRT button bars, MobaXterm macros, `.snippet` files and text files, with a preview of each snippet first.
- **More snippet steps.** `@pane left|right|up|down` and `@tab next|prev` move the rest of a snippet to another pane or tab. `@key` takes Ctrl, Alt and Shift with arrows, Home/End, Page Up/Down and F1-F12, several keys and counts (`@key down 3 enter`). `@delay 300ms` and `@pause 1.5s` take units.

## Changed

- **New tabs and splits start in the directory you're in.** This is now how every split and new tab works, so Window > Split right/down in same directory are gone. It works in tmux, in SSH shells (from OSC 7 or the prompt), and in local cmd and PowerShell tabs. A host's start directory is used when the directory isn't known.

## Fixed

- An imported port forward with an empty listening address (PuTTY's `D=2`, or `-D :1080`) read back differently after saving. It now means "all addresses", as it always did when used.
- A snippet line starting with `=` lost the `=` when it was read back, and a `"` in an imported name broke the saved file.

The fuzzer found the last two.
