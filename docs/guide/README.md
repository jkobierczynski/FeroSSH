# FeroSSH user guide

FeroSSH is a small, sandboxed SSH client for Windows: tabs, splits, tmux, file transfer, port forwarding and remote desktops in one exe with nothing to install.

1. [Getting started](getting-started.md): download, check and run it, and make your first connection.
2. [Everyday use](everyday-use.md): every feature explained: tabs and splits, workspaces, connecting (ssh_config, agent forwarding, Kerberos, reconnect), the tools pane, the connection and session managers, imports, password sources, backup and portable use, jump hosts and proxies, Mosh, WinRM, Telnet and serial consoles, login scripts and other scripts, the standby window, full screen, the command palette and key bindings, broadcast input, file transfer and ZMODEM, port and X11 forwarding, tmux, remote desktops and remote apps, fonts, themes and window colours, the server status bar, copying and scrollback, command suggestions, highlighting, making keys, security keys and updates.
3. [Menu reference](menus.md): every menu item and its shortcut, menu by menu, and the keys in each side pane.
4. [Logs](logs.md): session logs, timestamps, saving a pane's output, recording a pane and playing it back, and how sealed logs, `.chain` files and Check a log for changes work.
5. [Settings](settings.md): every keyword in `ferossh.conf`, with examples.
6. [Security](security.md): what the sandbox protects, how keys and passwords are handled, and which crypto is used.
7. [Verifying a download](verifying-downloads.md): checksums, build attestations and rebuilding a release yourself.
8. [Troubleshooting](troubleshooting.md): the problems people run into first, and what to do about them.

The [README](../../README.md) has the complete list of features and keyboard shortcuts.
