# FeroSSH user guide

FeroSSH is a small, sandboxed SSH client for Windows: tabs, splits, tmux, file transfer, port forwarding and remote desktops in one exe with nothing to install.

1. [Getting started](getting-started.md): download, check and run it, and make your first connection.
2. [Everyday use](everyday-use.md): tabs and splits, the session manager, file transfer, port forwards, tmux and remote desktops.
3. [Settings](settings.md): every keyword in `ferossh.conf`, with examples.
4. [Security](security.md): what the sandbox protects, how keys and passwords are handled, and which crypto is used.
5. [Verifying a download](verifying-downloads.md): checksums, build attestations and rebuilding a release yourself.
6. [Troubleshooting](troubleshooting.md): the problems people run into first, and what to do about them.

The [README](../../README.md) has the complete list of features and keyboard shortcuts.
